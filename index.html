规则说明

  • 基础分：一次消除 1 / 2 / 3 / 4 行，基础分依次为 120 / 360 / 720 / 1200。
  • 连消加成：连续消除行数不间断，每次连消提升 25% 分数。
  • 背靠背奖励：连续打出四消（Tetris）会获得额外 35% 奖励。
  • 时间段加成：游戏时间越久，加成倍数越高，最高可达 x2.0。
  • 等级速度：每 8 行升一级，速度曲线更平滑，后期更紧张。

关于这个小游戏

设计风格

采用暗色赛博 + 霓虹块状视觉，结合柔和阴影与发光边框，营造现代感的街机体验。

技术栈

原生 HTML5 Canvas + 原生 JavaScript 实现，便于你阅读和二次开发，无需任何第三方库。

可扩展性

你可以很方便地增加皮肤、音效、移动端自定义按键、更多难度模式或联网排行榜。
